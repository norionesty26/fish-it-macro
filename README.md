## What it does

One cycle is cast, wait, reel - and that is exactly what it repeats. You set how long each step takes, record the keys once from your own keyboard, and the loop runs until you stop it. A second sequence can be attached to the cycle for selling a full inventory, so a long session does not stall on a full bag.

## Features

- Cast, wait and reel repeated on a loop you configure
- Record the key sequence from your own keyboard
- Optional sell sequence so a full inventory does not stall the run
- Named profiles for different rods and spots
- Global hotkey to start and stop without leaving the game
- Random jitter on every delay
- Run counter showing completed casts
- Small installer, no extra components, free and open source (MIT)
